# Показ сайта Grechishkino

Финальные правки от 24.10 и текст "О нас" от 01.11. Обновление подготовлено 07.11.2026.

Просмотр: https://amdiyernest.github.io/grechishkino_pokaz/

Это статичная демонстрация внешнего вида, видео и галерей. Админка и сохранение заявок работают в полной серверной версии; формы демонстрации сообщают об этом при отправке.

Показ генерируется командой `npm run export:review` из рабочего приложения. В этот репозиторий не входят база, заявки, учетные записи и секреты.
