# grechishkino_pokaz

Дизайн-макеты сайта актёрского агентства Grechishkino (статичные HTML для согласования).

Открыть: **[index.html](./index.html)** - главная, дальше переходы по сайту.

Страницы: главная, каталог, профиль актёра, о нас, новости, контакты, политика, согласие на обработку ПД.

> Это демо-витрина макетов на этапе дизайна, не рабочий сайт. Разработка (Next.js + Payload CMS) ведётся в приватном репозитории.
